# Final Multi-Agent Audit

This folder contains the compact exported tables for the final recurrent CTDE-SAC run.

The run reduced aeration energy, pumping energy, external carbon dosing, and the partial controllable operating-cost components compared with the manual baseline. It did not improve the full logged objective, mainly because ammonium quality degraded.

That is the intended interpretation of this result: useful evidence that the MARL implementation and MATLAB/Python bridge work end to end, but not a claim of a deployable wastewater controller.
